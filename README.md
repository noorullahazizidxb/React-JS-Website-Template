# DevMinds — Our Works

Premium agency/portfolio showcase. Vite + React 19 + TypeScript, Tailwind CSS + shadcn/ui, framer-motion.

- `npm run dev` / `npm run build` / `npm run lint`
- Content lives in `src/data.ts`.
- **Logo:** replace `public/logo-light.svg` (light backgrounds) and `public/logo-dark.svg` (dark backgrounds). Referenced only in `src/components/Logo.tsx`. Favicon: `public/favicon.svg`; social image: `public/og.png`.
- Theme: light / dark / system (default), persisted in `localStorage`.

Live: https://ourworks.devminds.net
